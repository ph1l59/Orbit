FAQ

Questions? Answers.

Is Orbit free?

Yes – completely. No ads, no account, no paid features. Orbit is open source under the GPL-3.0 license, so anyone can read the code on GitHub.

Windows says the file could be dangerous. Is it safe?

Windows warns about programs that aren't signed with a paid certificate yet – that's all the message means. Orbit's whole code is public on GitHub, and every release is built automatically by GitHub from that code.

Click More info → Run anyway to start it. Only download Orbit from this website or the official GitHub page.

Where are my logins stored?

Only on your PC. You log in on the real roblox.com page, and Orbit keeps the login encrypted with Windows' own protection – it can only be read by your Windows user on your PC. Nothing is ever sent to us. Never share the file accounts.dat with anyone.

Can I get banned for using Orbit?

Orbit doesn't change or inject anything into the game. It starts Roblox the normal way, and settings and FastFlags only use what Roblox itself allows.

Some games have their own rules though, for example about auto clickers or playing with several accounts. Check the rules of the game you play – using those features is your own responsibility.

How do I run several accounts at once?

Turn on Multi-Roblox in Orbit, select your accounts on the Accounts page, paste a game link and press Launch. Orbit starts them one after another and keeps every window open.

How do I update Orbit?

You don't have to do anything. When a new version is out, a notice slides in – click Update Now and Orbit downloads, checks and restarts itself.

Is Orbit made by Roblox?

No. Orbit is an independent project by ph1l59 and is not affiliated with, endorsed by or associated with Roblox Corporation.
