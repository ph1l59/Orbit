## Orbit 2.0 – the big redesign
- **New "nebula" design** in dark purple
- **Settings search** – find any option from the sidebar
- **Global Settings** – graphics, FPS limit, sensitivity and more, can be locked
- **FastFlags** – presets plus a full editor with JSON import/export
- **Mods** – custom cursor, custom font and a mods folder
- **Bootstrapper** – Orbit installs and updates its own Roblox, with a cleaner for cache, logs and old versions
- **Integrations** – Discord Rich Presence, server location, programs that start with Roblox
- **Auto Clicker**
- **Online status** for every account
